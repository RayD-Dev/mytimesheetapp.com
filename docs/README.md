# Docs

| Folder | What | Master |
|---|---|---|
| `notion/` | Read-only copies of the PRD, HL design, system design, and FE and BE detailed design | Notion: comment and edit there, then run `/docs-sync` |
| `INDEX.md` | One line per requirement, decision, roadmap item and open question, pointing to its doc and section | Generated by `/docs-sync` |
| `screens/` | One spec per screen, written from the approved mock-up (`mockup/approved/`) | This repo |

`DESIGN.md` at the root holds the app-wide design rules. Plans and briefs live in `.claude/plans/`.
